What this build does

This is a static preview. It announces no event and sells nothing. It does not run a member login. It sets no cookies, loads no analytics, and sends no form, because there is no form. That sentence describes the build. It is not a registered privacy policy.

The only outbound link is the Instagram profile @lx.nsty. This site does not control that profile.

The NSTY wordmark in the header is an angular reconstruction of the lower lettering of the account mark, with the upper LX line omitted. It is not claimed as a pixel-perfect trace. Photographs are included only when supplied as account-authored or co-authored posts. Marks inside those photographs were not painted out.
